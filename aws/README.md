# AWS Deployment for CodeRunner

Multiple AWS deployment strategies from simple to enterprise-grade.

## **🎯 Recommended: AWS App Runner (Easiest)**

AWS App Runner is perfect for containerized applications like CodeRunner.

## **⚡ Alternative Options**
1. **AWS Lambda + API Gateway** (Serverless)
2. **Amazon ECS Fargate** (Containers)  
3. **AWS Elastic Beanstalk** (Platform-as-a-Service)
4. **EC2 + Application Load Balancer** (Full Control)
5. **AWS Amplify** (Full-Stack)

Choose based on your needs:
- **Learning/Demo**: App Runner or Amplify
- **Production**: ECS Fargate or EC2
- **Serverless**: Lambda (limited by execution time)
- **Enterprise**: ECS with RDS, CloudFront, etc.
